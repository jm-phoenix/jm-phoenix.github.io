Cómo funciona

  1. Configura una vez tu endpoint compatible con OpenAI, modelo y API key (quedan en tu navegador).
  2. Conversa: describe el equipo y la tarea; la IA pregunta lo que falta y busca datos técnicos en la web por ti.
  3. Edita el JSON generado con vista previa WYSIWYG en vivo y validación automática.
  4. Exporta la guía como un archivo HTML completo — con estilos, buscador de dudas por paso e imprimible.
