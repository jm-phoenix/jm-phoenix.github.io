隐私政策

最后更新：2026-11-05 · Inriris LLC · 波多黎各圣胡安 · webmaster@inriris.com

本隐私政策说明 Inriris LLC（"Inriris"、"我们"）在 SlugLauncher（"服务"）中如何处理信息。该服务是位于 https://git.inriris.com/launcher/ 的 Web 应用启动器。

1. 概述

  • SlugLauncher 无需账户。
  • 您的配置（应用、文件夹、标题、主题、语言）编码在您使用的 URL 中，而非我们的服务器上。
  • 打开启动器时，浏览器会联系第三方图标服务（Google favicon、您添加的网站，以及可选的 Iconify 或我们用于 SVGL 的 Cloudflare Worker）以显示图标。
  • 我们在您的浏览器本地存储少量偏好（主题、最近的哈希），并在 IndexedDB 中保存 图标缓存，有效期为 30 天。
  • 我们不出售您的数据。我们不使用广告 cookie。

2. SlugLauncher 存储什么以及存储在哪里

  • 在 URL 片段（#SLUG 之后）：应用、文件夹、名称、URL、图标 URL、页面标题、语言、主题及"已保存"标记。片段是您保存或分享的链接的一部分，浏览器不会将其发送到我们的服务器。
  • 在 localStorage 中：slTheme（您最近的主题选择）和 sluglauncher:lastHash（您最近的启动器，仅用于恢复在不带哈希的情况下打开的已安装应用）。
  • 在 IndexedDB（数据库 sluglauncher-icons）：您打开或分享过的图标缓存，最多保留 30 天，以便启动更快。您可随时在浏览器设置中清除。

3. 对第三方的请求

为显示图标，您的浏览器可能会联系第三方。这是正常的 Web 行为；我们无法控制这些第三方。请查阅其各自的隐私政策。

  • Google favicon 服务（www.google.com/s2/favicons）以及其他 Google 托管的服务（当您添加或打开使用 Google 提供图标的应用时）。
  • 您添加的网站——例如获取其 favicon.ico 或 og:image 元数据。
  • Iconify（api.iconify.design）——当您使用内置图标选择器并选择 Iconify 时。
  • SVGL（svgl.app）——当您使用选择器并选择 SVGL 时。请求可能通过由 Inriris 运营的 Cloudflare Worker（/launcher/icon-svgl 和 /launcher/icon-proxy）代理。
  • Cloudflare 作为 Inriris 前面的 CDN/托管提供商（可能根据其自身政策记录 IP 地址、时间和请求 URL 等技术数据）。

打开指向第三方图标、页面或服务的链接可能会向该第三方披露您的 IP 地址和请求技术数据。这是任何 Web 浏览的共性。

4. 我们不收集什么

  • 使用服务无需账户、电子邮件或密码。
  • 我们不出售或出租个人数据。
  • 我们不使用广告或跨站跟踪 cookie。
  • 我们不会故意收集 13 岁以下儿童的数据。

5. 服务器日志与安全

我们的托管和 CDN 提供商可能会自动记录技术数据（如 IP 地址、用户代理、时间戳和请求 URL），用于安全、防滥用和运营目的。这些日志依据这些提供商自己的政策处理，我们仅将其用于运营和保护服务。

6. 儿童

本服务不面向 13 岁以下儿童。如果您未满 13 岁，请勿使用本服务。如果当地法律规定了更高的最低年龄，则适用该年龄。如果您认为儿童向我们提供了个人数据，请联系我们，我们将采取合理措施删除。

7. 您的选择与权利

  • 您可以在浏览器设置中清除 localStorage 和 IndexedDB，以删除本地偏好和图标缓存。
  • 您可以随时停止使用本服务。
  • 根据您所在地区，您可能享有其他权利（访问、更正、删除）。如需行使，请发送邮件至 webmaster@inriris.com。

8. 数据保留

我们不维护启动器配置的中央数据库。本地偏好和图标缓存保留在您的浏览器中，直到您清除或过期（图标 30 天）。提供商侧的服务器日志按其政策保留。

9. 安全

我们采取合理的技术和组织措施保护服务。任何传输或存储方式都不是 100% 安全的；请自行承担风险使用服务，并避免在启动器名称、URL 或标题中放置机密信息。

10. 国际用户

本服务从波多黎各（美国）运营。如果您从美国境外访问，您是自愿访问，并负责遵守当地法律。

11. 本政策的变更

我们可能会不时更新本政策。页面顶部的"最后更新"日期将随之更改。重大变更将在此体现；在更新后继续使用服务即表示您接受修订后的政策。
